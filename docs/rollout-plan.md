# Four-week rollout (per client)

**Week 1 - Connect and baseline.** Fill `brief.md`. Confirm the primary conversion is a named GA4 event and fires (use the `im-analytics-tracking-qa` skill). Link GSC/GA4 property ids. Pull a few weeks of history into `state.json`. Set spend limits and approvals.

**Week 2 - Find the money page.** `/seo-pick-page`, then `/seo-audit-page`. Reject any finding without a source. Agree on ONE first change with the GM / Revenue Manager.

**Week 3 - Ship.** Agent drafts the change; a human reviews and publishes. Log the date and exact change; record baseline in `state.json` `active_experiment`.

**Week 4 - Measure.** Schedule `/seo-weekly`. Allow several more weeks before calling a win or miss. Next cycle: next change on the same page, or the next money page.

No sitewide audits up front; the weekly loop makes one decision a week.
